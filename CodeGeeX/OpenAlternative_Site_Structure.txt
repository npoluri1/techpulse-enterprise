SECTION 8: SAMPLE TOOL DATA FORMAT (from GitHub README awesome-list)
================================================================================

Format:
- **[Tool Name](https://openalternative.co/{tool-slug})** - Description `License` `⭐ Stars`

Examples:
- **[Aider](https://openalternative.co/aider)** - Terminal-based AI pair programmer `Apache-2.0` `⭐ 42K`
- **[n8n](https://openalternative.co/n8n)** - Self-hosted workflow automation `⭐ 188K`
- **[Ollama](https://openalternative.co/ollama)** - Run LLMs locally `⭐ 171K`
- **[Open WebUI](https://openalternative.co/open-webui)** - Self-hosted AI interface `BSD-3-Clause` `⭐ 138K`

Each listing in the directory includes:
  - Name + slug (e.g., "aider" -> /aider)
  - Short description (1 sentence)
  - License tag (MIT, Apache-2.0, AGPL-3.0, etc.)
  - GitHub Stars count
  - Category tags (e.g., "AI Coding", "Self Hosted", "CLI")
  - GitHub repo link (fork, star, last commit data)
